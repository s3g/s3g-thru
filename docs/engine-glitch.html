Glitch

Glitch continuously records each voice into its own short history, then replaces selected moments with repeating fragments. A rotating pulse pattern decides when overrides happen; deterministic history jumps, pitch changes, reversals, shrinking loops, and a performable history lock make the result repeatable without becoming regular.

Controls edit the focused instrument. Instrument mode sets its lane and voice budget: eight voices in Single, four per part in either dual mode, or two per part in Quad. Quad omits stack controls because each part has one lane.

Good for: hard stutters, unstable meters, asymmetric accents, repeat-buffer interruption, abrupt silences between dense events, and patterns that can be recalled exactly by Seed.

Pages and navigation

Set Algorithm to Glitch. Up opens the shared Pads & Scale and Amp Envelope pages, followed by Stack Path, Glitch Clock, and Glitch Pattern. Every held voice owns an independent history buffer and pattern counter.

The controls common to every playback engine are documented in the shared Engine page table. Stack Path keeps moving each voice through its four-lane Single or Shared Dual stack, or two-lane Split stack while its history is being filled.

Buffer Lock

Hold Shift + Loop to freeze the recent history owned by every active Glitch voice. Release the chord to return to live capture. Tap the chord twice quickly to latch the histories, then press it once more to release the latch. Plain Loop remains Stack Hold, so lane motion and buffer capture can be stopped independently.

The Loop key turns orange and the display shows LOCK while Buffer Lock is active. Pattern, Stack Path, note pitch, and Effects continue to run against the fixed captures. A voice triggered while locked first fills its own approximately 171 ms history and then freezes; it does not borrow another voice's material. Locked audio is temporary and is not written into the clip bank—use Resample when the captured result should become a saved lane.

Performance tip: lock a useful moment, then automate Steps, Pulses, Rotate, and Override in a performance loop. Buffer Lock itself remains a live gesture; Resample commits the result when needed.
