Grains

Grains launches overlapping, windowed readers from a moving, frozen, random, or sliced source position. It can also reorder equal source regions from quietest to loudest. Keyboard notes transpose the grains while Speed moves the source trajectory independently.

In Split, these controls edit the focused A or B instrument. Its two lanes and four voices are independent of the other side. See Split focus and waveform zoom.

Good for: freezes, clouds, independent time/pitch motion, stereo spray, regular or scattered textures, rhythmic doublets, stutters, shrinking grain trains, and energy-ordered phrases.

Pages and navigation

Set Algorithm to Grains. Up first opens the shared Pads & Scale and Amp Envelope pages, followed by Stack Path, Grains Main, Grains Cloud, and Grains Process.

The controls common to every playback engine are documented in the shared Engine page table. The sections below cover Grains-specific controls.

KnobDisplayRangeDetail
1PROCOrdinary / Stutter / Shrink / Doublets / SorterOrdinary leaves events unchanged. Stutter groups grains at one source anchor. Shrink shortens successive grains in an eight-event cycle. 2PAMT0.00–1.00Process strength: up to 16-grain Stutter groups, 85% Shrink depth, increasingly close Doublet pairs, or a blend from the ordinary origin to the energy-sorted region.

5ADVNScan / Per GrainScan advances source phase continuously. Per Grain advances the origin only when a grain launches; paired Doublets share an origin.
6QUAL4 / 8 / 16 voicesMaximum simultaneous grains inside each playback voice. More slots permit denser long grains but increase Move CPU cost.
7–8Reserved—Inactive positions available for future Grains Process controls. Path is on Stack Path; Scan Rate is on Engine.

Move performance: start with Quality 8. If System Report shows increasing Deadline Misses, reduce Quality to 4, reduce Density, shorten Size, or release some playback voices. Use Quality 16 when Deadline Misses stays at zero.
