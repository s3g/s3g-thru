Lanes

Lanes separates motion through time from motion through the four-source stack. Each voice reads Forward, Reverse, or Ping Pong while its own shaped stack path chooses a lane or crossfade.

Good for: treating four variations as a single evolving instrument, pressure-directed morphs, stepped lane sequences, smooth cyclic crossfades, and pitch-preserving duration changes.

Lanes Path — every parameter

KnobDisplayRangeDetail
1MODEForward / Reverse / Ping PongSelects the direction used to read every active lane. Ping Pong travels out and back at the same audible pitch as the other modes.
2PATH8 choicesChooses how stack position moves: Down, Up, Triangle, Sine, Steps Down, Steps Up, Manual, or Random.
3RATE0.125–16 HzStack-path cycles per second. Every voice owns its own phase and pressure offset.
4STAK1.00–4.00Stack Start. Manual uses the exact continuous lane position; moving paths use it as the voice's phase seed.
5BLNDCrossfade / JumpCrossfade blends adjacent loaded lanes with a smooth equal-position curve. Jump chooses the nearer loaded lane.
6SHAPLinear / Smooth / Exponential / PlateauRemaps the path output before it becomes a 1–4 lane position. Plateau quantizes the result into four levels.
7FLD0.02–1.00Source-window width shared by the lane readers.
8JOIN0.00–1.00Read-head seam and reversal smoothing inside the source window.

Path choices

PathStack movement
DownContinuously moves lane 1 → 4, then wraps.
UpContinuously moves lane 4 → 1, then wraps.
TriangleLinear 1 → 4 → 1 travel.
SineA smooth triangle with slower, zero-slope turns at lanes 1 and 4.
Steps DownVisits four descending positions with hard phase steps; Transition and Jump Slew determine the audible edge.
Steps UpThe reverse four-step sequence.
ManualStops automatic lane travel and reads Stack Start as a continuous lane/crossfade position.
RandomUses a deterministic 16-step random path, repeatable when the same state is recalled.

Lanes Shape — every parameter

KnobDisplayRangeDetail
1OFST0.00–1.00Rotates the whole stack-path phase and wraps at 1.00. This shifts every breakpoint without changing speed.
2SKEW0.02–0.98Moves the halfway point in time. Below 0.50 reaches the path midpoint early; above 0.50 reaches it late.
3CURV−1.00–1.00Bends phase before Path is evaluated. Negative values move quickly early and ease late; positive values ease early and accelerate late.
4SLEW0–500 msOne-pole smoothing for lane-weight changes. 0 is immediate; higher values soften Jump, stepped paths, and live path edits.
5STROff / OnEnables time stretching when Ratio differs from 1.00, without intentionally changing pitch.
6RATI0.25–4.00×Sets stretch duration: values above 1 lengthen playback and values below 1 shorten it while keeping pitch as steady as possible.
7SPD0.05–4.00×Source pitch/transport before Stretch Ratio modifies duration.
8LEVL0.00–2.00Final output gain.

Pressure is an offset, not a replacement path. Strike velocity seeds a voice offset and poly pressure moves it while held. The underlying Scan Rate continues unless Loop holds the stack scan.
