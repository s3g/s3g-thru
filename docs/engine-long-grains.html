Long Grains

Long Grains launches one to four overlapping macro-events lasting from 250 ms to 12 seconds. Each event captures its own source position and lane blend, so stack motion becomes a slowly changing layer of sustained sample fragments rather than a dense grain cloud.

Good for: stretched phrases, overlapping tape-like layers, slowly separating stereo voices, long reversals, held textures, and transitions that preserve the attack and internal motion of the source.

Pages and navigation

Set Algorithm to Long Grains. Up opens the shared Stack Path page, then Long Grain and Long Motion.

The controls common to every playback engine are documented in the shared Engine page table. The sections below cover Long Grains-specific controls.

Long Grain — every parameter

KnobDisplayRangeDetail
1MODEScan / Freeze / Cloud / SliceScan follows source phase; Freeze launches from Field center; Cloud chooses a random origin; Slice places the active layers at evenly spaced origins across Field.
2LEN250–12,000 msNominal duration of each event. The encoder uses fine 10 ms steps to 1 second, 50 ms steps to 4 seconds, then 100 ms steps to 12 seconds.
3LAYR1–4Maximum simultaneous long events per note. New events are spaced across the longest possible varied duration, keeping the renderer bounded to this count.
4PIT0.25–4.00×Playback ratio inside each event. Pad pitch controls the source trajectory separately.
5SHAPBell / Hann / Triangle / PlateauSelects the event envelope. Bell, Hann, and Triangle span the complete duration. Plateau uses Edge for short fades with a sustained center.
6EDGE5–2000 msFade-in and fade-out time for Plateau. It is limited automatically to half the current event duration. Other shapes ignore this control.
7SPRD0.00–1.00Random constant-power stereo pan range for each new layer.
8REV%0–100%Probability that a new layer reads backward.

Long Motion — every parameter

KnobDisplayRangeDetail
1SPRY0.00–1.00Random displacement from the mode-selected origin, up to half the Field width at 1.00. Displacement wraps inside Field.
2BIASBehind / Around / AheadConstrains Position Spray behind the origin, on both sides, or ahead of it.
3DVAR0.00–1.00Varies each event duration by up to approximately ±75%. Launch spacing remains conservative so the selected layer limit is not exceeded.
4PSPR0–24 stApplies a random pitch offset inside ± the selected semitone range to every new layer.
5LVAR0.00–1.00Random attenuation only: 0 keeps nominal level; 1 ranges from nearly silent to nominal.
6PHAS0.00–1.00Offsets successive layer origins across Field. At 1.00, the available layers divide one complete Field cycle.
7ADVNScan / Per LayerScan follows continuously moving source phase. Per Layer advances the source origin only at the layer launch interval.
8Reserved—Inactive and available for a future Long Motion control.

Starting point: use Length 4000 ms, Layers 3, Plateau, Edge 180 ms, Spread 0.65, Phase 0.40, and Per Layer advance. Raise Position Spray or Pitch Spray only after the overlap is clear.
