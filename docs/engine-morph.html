Morph

Blend the spectral amplitudes and frequencies of a source with those of the next lane. The two controls move independently, making hybrid sounds that go beyond a volume crossfade. Imprint mode lets the next lane’s changing spectral envelope articulate the carrier while notes control its pitch.

Good for: Hybrid voices, moving spectral colors, independent amplitude and frequency transformations, and a circular four-lane instrument in Quad.

Pages and navigation

Choose Morph with Algorithm on the shared Engine page. Up/Down reaches Pads & Scale, Amp Envelope, Stack Path, and the Morph page. Quad omits Stack Path because each part owns one lane. The remaining shared pages work as described in the shared Engine table and Stack Path reference.

Imprint — one sample articulates another

Select IMPR with knob 6 and raise knob 1 / IMPR toward 100%. A rich sustained recording in the carrier lane can take on the articulation of speech or percussion in the next lane. Keyboard notes and PIT transpose the carrier; the shaping envelope stays in its original frequency regions. Stack travel changes the carrier/shaper pair. Quad keeps each carrier on its own lane and uses the next lane as shaper, wrapping 4 → 1.

OFST chooses a different point in the shaping recording; BLUR smooths its articulation. At full strength, a silent shaping recording closes the carrier. A missing or unprepared shaping lane temporarily leaves the carrier unshaped. A sine carrier has few partials to shape; a harmonically rich or noisy carrier gives a clearer result. Imprint preserves the carrier’s stereo image with linked envelope control and limits boosts in weak bands.

This adapts the envelope-transfer approach described in CDP FORMANTS VOCODE / SPECENV for Thru’s prepared spectral framework.

Playing, lanes, and preparation

Notes set pitch. Speed controls movement through the source independently. The shared Amp Envelope sets note attack and release. Single provides eight note voices; both dual modes provide four per part; Quad provides two per part. Each note follows its own stack path and phase. Loop holds stack travel in Single and dual modes.

Source analysis runs in the background after loading, recording, or editing a lane. SPECTRAL PREPARING means the spectral source is not ready yet; wait for preparation to finish. Newly prepared data is shared by all notes. These engines resynthesize spectral frames, so they can sound softer or more diffuse than direct Sample playback. They do not pass through the unprocessed sample.

Live edits smooth spectral amplitudes and frequencies while synthesis continues with overlapping windows. Join sets a short minimum smoothing time underneath Blur. Stack travel moves the main source and its next-lane partner together.

ModeSource pairing
Single / Shared DualLane 1 → 2, 2 → 3, 3 → 4, 4 → 1. An in-between stack position blends the corresponding source pairs.
SplitA wraps between lanes 1 and 2; B wraps between lanes 3 and 4.
QuadA uses 1 → 2, B uses 2 → 3, C uses 3 → 4, D uses 4 → 1.

The partner is the neighboring lane’s recording before that other part’s engine, mute, level, or effects. It does not consume another note voice. If no partner source is ready, Morph uses the main source for both sides. Load the neighboring lane and wait for preparation to hear the full morph.

Starting points

Load contrasting recordings into neighboring lanes. Start with Amplitude 50%, Frequency 50%, Offset 0%, Blur 40 ms, and Pitch 0. Move Amplitude and Frequency separately, then try Quad to play all four cyclic pairings.
