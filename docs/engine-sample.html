Sample

Sample is the direct reader: every note selects one discrete lane, then plays the Position/Field window as a one-shot, loop, or ping-pong voice. It is the clearest engine for pitched polyphony and for hearing a lane without continuous stack motion.

Good for: conventional sample playback, pitched chords, sustained loops, reverse one-shots, velocity-addressed lane layers, cue points, and tempo-synced rolls.

Page and navigation

Set Algorithm to Sample. Up opens the shared Direct Play page used by both Sample and Slices.

The controls common to every playback engine are documented in the shared Engine page table. The sections below cover Sample-specific controls.

Direct Play — every parameter

KnobDisplayRangeDetail
1PLAYForward / Reverse / Loop / Ping PongChooses the read direction and whether playback stops or repeats at the Position/Field boundaries.
2VARIManual / Cycle / Random / No Repeat / VelocityChooses how a lane is assigned when each new voice starts. The lane remains fixed for that voice.
3PADSKeys / Slices / Cues / RollsChanges what the 32 pads address. See the complete behavior table below.
4ROOTC1–C7Sets the common pitch used by Slices and Rolls. Keys keeps its isomorphic note grid.
5–8Reserved—Inactive positions available for future direct-play controls.

Play Mode choices

ModeBehavior
ForwardReads once from the start to the end of the current window, then becomes silent.
ReverseReads once from the end to the start of the current window, then becomes silent.
LoopRepeats forward through the window for as long as the voice remains active.
Ping PongAlternates forward and backward at the same audible pitch as the other modes.

Variation choices

VariationLane selected at note-on
ManualThe nearest whole lane selected by STAK.
CycleThe next loaded lane in order, wrapping after the last.
RandomAny currently loaded lane.
No RepeatA random loaded lane, advanced to another lane if it would repeat the previous choice.
VelocityDivides the velocity range across the loaded lanes. A harder strike chooses a higher lane, but does not make the voice louder.

Pad Mode choices

Pad modeWhat the 32 pads do
KeysPlay an isomorphic pitched layout around Root. Every voice reads the whole current window.
SlicesAll pads play Root pitch. In Sample, the whole window still plays; choose the Slices engine when each pad should address a region.
CuesRecall stored cue positions. Shift + a cue pad stores the current position; Delete + the pad clears it.
RollsEach held pad starts a temporary tempo-clocked Cutups voice at a pad-specific division.

Lane selection is not lane scanning: Variation chooses one lane for a voice at note-on. Pressure can still offset engines that scan the stack, but it does not crossfade an active direct Sample voice to another lane.
