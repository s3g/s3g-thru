Slices

Slices plays equal divisions, detected transients, imported WAV markers, or your own edited regions. Pads and MIDI keys choose a slice, and held slices can overlap within the part’s voice budget. Every voice still has independent pitch, direction, loop behavior, and a discrete lane.

Controls edit the focused instrument. Instrument mode sets its lane and voice budget: eight voices in Single, four per part in either dual mode, or two per part in Quad. Quad omits stack controls because each part has one lane.

Good for: drum chopping, transient performance, chromatic slices, repeated regions, velocity-layered slice sets, cue triggering, and tempo rolls.

Pages and navigation

Set Algorithm to Slices. Up opens the shared Pads & Scale and Amp Envelope pages, then Direct Play and the unique Slice Source page.

The controls common to every playback engine are documented in the shared Engine page table. The sections below cover Slices-specific controls.

Slice Source choices

SourceHow boundaries are made
EqualDivides the outer Position/Field window into SLIC equally sized regions.
TransientsUses up to 64 automatically detected regions for the chosen lane. PRER can start playback a few milliseconds before each onset. Falls back to Equal if no map is available.
FileUses embedded RIFF/WAV cue points, sorted by position. WAV labels name the slices in Slice Edit. A beginning boundary and an end boundary are supplied automatically. Falls back to Equal without usable markers.
EditedUses your saved boundary edits for this clip and lane. Before the first edit, starts from File if available, then Transients, then Equal.
AutoChooses Edited first, then File, then Transients, then Equal.

SLIC changes only equal divisions. Pad numbers wrap through the available regions. File import supports the standard WAV cue points and optional LIST/adtl/labl names. Markers outside the loaded audio are discarded; duplicate positions are merged. A map holds at most 64 slices. LIMIT64 in the editor means extra markers were omitted.

Slice Edit

Open Slice Source and click the main encoder. Track 1–4 selects a loaded lane belonging to the focused part. The header shows lane, selected slice/count, its WAV name when available, and the current/total pad-bank fraction at the right edge. The selected slice has start and end caps; other cuts appear as dotted marks. A small lead-in bracket shows PRER. Zoom in and turn the main encoder to scroll the waveform beneath the central edit cursor. At the full overview, the cursor moves across the file.

KnobDisplayRangeDetail

3ENDBetween adjacent boundariesEnd boundary. Turn to move it; Shift gives the same fine adjustment. Moving a shared cut also changes the following slice’s start.
4ZOOM1×–65536×Waveform magnification around the edit cursor. Detail is prepared in the background; playing notes continue while the display updates.
5PRER0–30 msPre-roll: begin playback this far before the nominal slice start, clipped to the source window. Adjust by 1 ms, or 0.1 ms with Shift. Applies to this clip’s lane; nominal cuts and preceding slice ends stay in place.
6–8Reserved—Unused controls, shown as small boxes.
ControlAction in Slice Edit
Main encoder turnPlace the edit cursor. Movement follows the current zoom; Shift gives 0.1 ms steps.
Main encoder clickAdd a cut at the cursor. The new slice becomes selected. Maximum 64 slices.
Pad / Shift + padSelect and audition a slice / latch the audition. Shift + the same pad stops a latched audition. Only the focused part’s pads become slice selectors; other parts keep playing normally.
LoopToggle repeating audition. ONCE plays the selected slice once; LOOP repeats while held or latched.
Up / DownNext / previous slice-pad bank. Single presents 32 slices per bank, either dual mode 16, and Quad 8. Step buttons retain clip selection.
Delete (X)Remove the highlighted interior boundary and merge its neighbouring slices. Turn STRT or END to choose which boundary is highlighted. First and last boundaries cannot be deleted.
Undo (curved arrow)Undo the latest boundary or pre-roll edit. Continuous turns are grouped into one edit; stop performance/audio recording before undoing.
Back / MenuStop audition and return to Slice Source.

The first boundary edit creates an independent Edited map for this clip and lane, preserving the current source map as a starting point. Edits and PRER are saved with the clip and follow clip copies and source inheritance. Loading a replacement sample or making a new lane recording clears that lane’s old edits. File markers are read again when their WAV is recalled. Saved marker maps survive normalization and fades; destructive Reverse and Trim move both imported and edited boundaries with the audio.

New transient maps default to 3 ms pre-roll; File and Equal default to 0 ms, preserving authored marker timing. The first explicit PRER setting overrides that default for the lane. Sets saved before Slice Edit retain their previous 1 ms transient lead-in when upgraded.

Existing performance notes keep their original slice boundaries until the next trigger; source-lane changes resolve the map for the new lane. The editor’s audition follows edits with a short reader crossfade and uses one of the part’s existing voices. Audition gestures are excluded from performance recording; record normal slice playing after leaving the editor. JOIN still controls loop seams, so increase it when a loop edge sounds abrupt.

Play Mode choices

ModeBehavior inside the chosen region
ForwardReads once from the region start to its end, then becomes silent.
ReverseReads once from the region end to its start, then becomes silent.
LoopRepeats forward inside the region while the voice is active.
Ping PongAlternates forward and backward at the same audible pitch as the other modes.

Variation choices

VariationLane selected at note-on
ManualThe nearest whole lane selected by STAK.
CycleThe next loaded lane in order, wrapping after the last.
RandomAny currently loaded lane.
No RepeatA random lane, moved to the following loaded lane if it repeats the previous choice.
VelocityDivides strike velocity across loaded lanes without changing output amplitude.

Each note keeps its chosen lane while it plays. The unused RATE position is reserved on the waveform and Engine pages. Use STAK with Manual variation to choose the lane for the next note, or another Variation choice to change lanes at note-on.

The activity bars beside the lane numbers follow the latest held voice in Single mode. Each playhead’s square marks its own source lane. In Split, Shared Dual and Quad, the bars show the combined activity of the voices. They follow the actual slice readers rather than the unused stack scan.

Pad layouts

See the shared Pads & Scale reference for every layout and scale. In Keys, physical pad identity chooses a region while its mapped note also transposes that region. In Slices, pad identity chooses the region and every pad plays at Root pitch.

From an external MIDI keyboard or sequencer, the part’s Root note selects slice 1; each semitone above it selects the next slice, wrapping after the last region. Notes below Root select slice 1. All slices play at SPEED without keyboard transposition; pitch bend and Engine List octave variation remain available. See MIDI slice playing for routing and an example.

Source window: Equal divides the current Position/Field window. Detected, File and Edited maps keep their positions in the full recording; Position/Field clips their playable range. A slice outside the window is silent. The editor auditions the full selected lane so a cropped performance window does not hide the cut being edited.
