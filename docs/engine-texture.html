Playback engine 12 of 13

Texture

A held note becomes a small sample phrase: scattered events, grouped bursts, repeated pitch contours, or ornaments. Each note keeps its own source path and a bounded set of overlapping stereo events.

Good for: Playable sample textures, generated motifs, scattered layers, and short ornamental phrases.

Pages and navigation

Choose Texture with Algorithm on the shared Engine page. Up/Down reaches Pads & Scale, Amp Envelope, Stack Path, and the Texture page. Quad omits Stack Path because each part owns one lane. The remaining shared pages work as described in the shared Engine table and Stack Path reference.

Texture — every parameter

KnobDisplayRangeWhat it controls
1MODESpray / Grouped / Motif / OrnamentMode selects Spray, Grouped, Motif, or Ornament. Spray scatters independent events; Grouped introduces gaps between event groups; Motif repeats a pitched contour and spaced source positions; Ornament adds shorter notes around each main event.
2RATE0.25–24 HzTexture event rate sets the underlying event launches per second. Scatter and grouped or ornamental timing modify this spacing. Four internal events per held note keep the voice cost bounded; a full event pool skips a new launch.
3LEN20–2000 msTexture event length sets each new sample event’s duration. Existing events finish with their captured timing. Ornament notes are shorter than the main event. Dense, long events may fill the four-event pool.
4SCAT0–100%Texture timing scatter varies intervals between event launches. In Grouped mode it also varies source positions slightly. Zero keeps regular base timing.
5RNGE0–24 stTexture pitch range limits generated semitone intervals around the played note. The selected Pads & Scale scale quantizes these intervals; zero keeps the played pitch. Spray and Grouped use both directions, Motif builds an upward contour, and Ornament moves around the main note.
6GRUP2–8Texture group size sets the length of a repeated motif, an ornament group, or a group before a pause. It is reserved in Spray mode.
7SPRD0–100%Texture stereo spread distributes events toward the left and right while keeping the recorded stereo pair together. Zero centers placement; 100% gives the widest distribution.
8SEED1–9999Texture seed chooses a reproducible sequence of random variations. Each played voice has its own variation. A new seed is adopted at the next group boundary, while already sounding events finish normally.

MIDI: CCs 40–45 address the first six engine-page knobs. Texture Spread and Seed use CCs 28 and 29. Values are absolute 0–127, scaled to the displayed range. Unused slots are reserved; the MIDI channel selects the part as described in External MIDI.

Playing, lanes, and preparation

Notes set pitch. Speed controls movement through the source independently. The shared Amp Envelope sets note attack and release. Single provides eight note voices; both dual modes provide four per part; Quad provides two per part. Each note follows its own stack path and phase. Loop holds stack travel in Single and dual modes.

Each held note can run four internal events. Each event captures its pitch, stereo placement, lane blend, source region, and edge fades at launch. Pressure, stack travel, and parameter edits shape later events while existing ones finish. Join controls the short launch, release, and loop-edge fades. Loaded transient regions guide event starts when available.

Starting points

Start with Motif, Rate 4 Hz, Length 250 ms, Scatter 20%, Range 7 semitones, Group 4, Spread 50%, and Seed 1. Select a scale on Pads & Scale and hold a note. For a regular same-pitch phrase, set Range and Scatter to zero.
