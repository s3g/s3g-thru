Sound layer

Playback engines

Thirteen engines reinterpret the same four stereo lanes. Start here to compare them, then open an engine guide for every parameter, option, range, and interaction on its contextual pages.

The title-row fraction shows the current parameter page and the number available for the selected engine. The examples describe Single mode; dual modes add setup and sends pages, while Quad omits stack controls and uses its own sends and setup. The total also changes with the engine: Sample has the shortest set, while Grains and the extended Motion modes have more contextual pages. The screen examples therefore show the correct fraction for the engine used in each figure rather than one global page count.

Instrument modes: Single, Split, Shared Dual, and Quad use different lane layouts and voice budgets. Compare the modes and choose a layout before following the controls below.

6RATE / ADV0.125–16 Hz; Cutups Hold / 1 / 2 / 3 / 4 / 8 / 16 cutsScan Rate sets cycles per second for moving stack paths. Loop freezes the audible phase. Cutups replaces this knob with ADV: Hold or 1/2/3/4/8/16 cuts per lane. Sample and Slices do not use continuous stack scanning.
7JOIN0.00–1.00Join scales seam smoothing for continuous/event readers and the Sample engine's Loop boundary. Motion also uses it as articulation depth. Cutups has a separate Cut Join for event-to-event fades. At zero, a very short internal safety transition remains to prevent a one-sample edge.

One control, one location: a parameter appears on only one parameter page. Shared pages retain the same knob positions wherever they appear. A small hollow box marks an unassigned encoder position reserved for a future control; turning that encoder does nothing.

Shared Pads & Scale page

This page follows Engine for every playback algorithm. It chooses what the 32 pads do and, in Keys mode, whether they use the original chromatic layout or a folded scale layout.

KnobDisplayRangeWhat it controls
1PADSKeys / Slices / Cues / RollsChooses how the 32 pads address pitches, regions, stored positions, or clocked rolls.
2ROOTC1–C7Sets sample unison and the tonic of a named scale. Slices play this pitch; Rolls retain the pitches already present in their grouped capture. In a named Keys scale, the bottom-left pad begins one octave below Root before octave transposition.
3SCALChromatic + 24 scalesChromatic preserves the original semitone grid. A named scale removes out-of-scale pitches and maps adjacent columns to consecutive scale degrees.
4HOLDManual / 50 ms–60 sKeeps Shift+pad latches active until toggled, or schedules their release with one delay per instrument: shared across Single, independent for A and B in either dual mode.
5POLYOff / OnPolyphony Compensation smoothly controls summed energy as simultaneous source voices and Rolls increase. One voice remains unchanged. Turn it off only when intentional additive buildup is part of the sound.
6PRESOff / OffsetPressure enables per-pad pressure offsets through the stack for the focused instrument. A and B keep independent settings. Reserved in Quad, where each part has only one lane.
7–8Reserved—Inactive positions available for future pad-layout controls.

From 0.29.0-test.2, storing a cue also remembers the owning part's latest playhead lane/blend. Recall holds that blend and aligns the Stack Start value with it. Turn Stack Start to move the held blend; this leaves the stored cue unchanged. Loop resumes the scan. Delete + cue pad clears it. Cues saved by older releases remain time-only until stored again.

Named scales retain an overlapping isomorphic shape: each row begins three scale degrees above the row below. Up/Down moves the complete layout by octaves. Scale affects the Move pads only; external MIDI and notes already stored in a performance clip are not quantized or rewritten.

Shared Amp Envelope page

Amp Envelope follows Pads & Scale for every playback algorithm. It shapes the amplitude of each of the eight source voices independently after that voice's playback engine. Pad velocity does not change amplitude.

KnobDisplayRangeWhat it controls
1ATK0 ms–10 sAttack time from silence or the current retrigger level to full amplitude.
2DEC0 ms–10 sDecay time from the attack peak to Sustain. Values below 1 ms retain a 1 ms safety ramp when Sustain is below the attack peak.
3SUS0–100%Sustain level held while the pad, latch, or recorded note remains on.
4REL0 ms–20 sRelease time from the current level to silence after note-off. The 0 ms setting retains a transparent 3 ms safety taper.
5–8Reserved—Inactive positions available for future envelope controls.

The time knobs use close-spaced millisecond values near zero and progressively wider steps for long fades. The default 3 ms attack, 0 ms decay, 100% sustain, and 25 ms release preserves the earlier immediate pad response while suppressing clicks. Replaying a note during a long release leaves its old tail on a separate voice when capacity permits; when the available voices are occupied (eight in Single, four per part in Split), the reused voice fades out before its reader restarts. Envelope gestures recorded into a performance clip replay with that clip. Rolls use a captured, already-enveloped stereo fragment and retain their separate short edge crossfade; the Amp Envelope is not applied a second time.

For a hands-on grouped roll, latch a chord in Keys, change PADS to Rolls, and press a division pad. The latched source voices remain active through the mode change and become the roll's combined capture.

Roll fragment length follows its division and the BPM at capture. The original playheads continue advancing silently while a roll is active, so releasing it returns to the live performance rather than a frozen source position. A 3 ms internal crossfade suppresses boundary clicks, and grouped rolls do not consume or steal any of the eight source voices. Performance recording stores the pad gesture and division; on replay, that event captures the active playhead group at the recorded moment.

Shared Stack Path page

Motion, Lanes, Grains, Glitch, Weave, and Wavesets all use this same page to shape movement through all four lanes in Single and Shared Dual, or the focused pair in Split. Stack Start and Scan Rate remain on Engine and are not repeated here. Quad omits this page because each part owns one lane. Its discrete VARI control also stays on that assigned source.

KnobDisplayRangeWhat it controls
1PATH13 choicesChooses Down, Up, Triangle, Sine, Steps Down, Steps Up, Manual, Random, or an editable Draw route through the stack.
2BLNDCrossfade / JumpCrossfade blends adjacent loaded lanes; Jump selects the nearer loaded lane.
3SHAPLinear / Smooth / Exponential / PlateauChanges the contour of the path before it becomes a lane position.
4OFST0.00–1.00Rotates the path through one complete cycle without changing Scan Rate.
5SKEW0.02–0.98Moves the path's halfway point earlier or later in the cycle.
6CURV−1.00–1.00Bends travel toward a faster start or a faster finish.
7SLEW0–500 msSoftens abrupt lane-weight changes, especially with Jump and stepped paths.
8Reserved—Inactive and available for a future Stack Path control.

Editable stack paths

Requires 0.29.0-test.3 or newer. On Stack Path, turn PATH to DRAW, then click the main encoder to open Path Editor. You can also reach it as the next parameter page or through Capture + Menu. It appears only while DRAW is selected.

KnobDisplayRangeWhat it controls
1PT1–point countSelected breakpoint. Its time, lane, and outgoing curve appear under knobs 2–4.
2TIME0–99%Point time within one cycle. The first point stays at 0%. Other points stay ordered, at least 1% apart.
3LANE1.00–4.00, or the owning pairLane position, including blends. Split B shows physical lanes 3–4. Repeated lane values at adjacent points make a pause.
4CURV−100–100Curve from this point to the next. Zero is linear; positive values start slowly and accelerate; negative values start quickly and slow down. The last point controls the return to the first.
5PNTS4–8Point count. Turning up inserts after the selected point while preserving the existing curve. Turning down removes the selected point; if the first point is selected, it removes the last instead.
6–7Reserved—Inactive positions, shown by hollow boxes.
8RSETShift + turn clockwiseRestore the four-point triangle. The curved-arrow Undo key can restore the previous edit.

To make a pause, give two adjacent points the same LANE value and separate their TIME values. Playback continues within the held lane. To revisit a layer, use its LANE value again later. Uneven times change travel speed between visits. If a segment is too short to add another point, choose a different point or move its neighbors apart.

Scan Rate on Engine or the waveform page sets the cycle speed; point times are percentages of that cycle. OFST rotates the route. SLEW smooths audible transitions, so very short pauses at a fast rate may be softened. Back returns to Stack Path.

All voices in a part use the same authored shape with their own existing phases. Editing the shape keeps those phases running. Motion packets, Grains, and Weave follow live edits without restarting their events. Glitch reads new source positions when its buffer refreshes. Loop freezes travel; recalled cues and Capture lane grabs retain their explicit lane positions until released.

Paths are stored per clip and per part. Single uses four lanes; Shared Dual has independent A/B paths over all four; Split maps each path across its owning pair. Quad, Sample, Slices, and Cutups do not show this editor. Switching to a named path leaves the authored points available when you return to DRAW.

Record captures point and curve edits as performance data. Replace and Overdub keep their usual behavior, and Undo Take removes the path edits made in that take.

What every engine shares

Single shares eight voices across the clip’s four lanes. Split gives each instrument four voices across its own two lanes; Shared Dual gives each four voices across the same four sources, using the same or different engines with independent settings. Quad gives each of four parts one lane and two voices. Each voice has its own pitch, read position, release, and physical pad assignment. Motion, Lanes, Grains, Glitch, Weave, and Wavesets also give every voice its own movement through the stack; Cutups advances each voice’s discrete lane after a chosen number of cuts. Sample and Slices choose discrete lanes.

After the engine’s contextual pages, the shared pages appear in this order:

ModePage order
SingleMix / Rec → Effects → Stereo / Rotary → Tape → Reverb → FX Order → Sample Edit → Performance Loop → Overdub Takes → Chain.
Split / Shared DualFX Sends → Dual Setup → Mix / Rec → Part Color → Stereo / Rotary → Delay Return → Tape → Reverb → FX Order → Sample Edit → Performance Loop → Overdub Takes → Chain.
QuadFX Sends → Quad Setup → Mix / Rec → Part Color → Stereo / Rotary → Delay Return → Tape → Reverb → FX Order → Sample Edit → Performance Loop → Overdub Takes → Chain.
