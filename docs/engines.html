The shared Engine page

KnobParameterRangeWhat it controls
1Algorithm6 choicesSelects Motion, Lanes, Grains, Cutups, Sample, or Slices. Up/Down then shows the pages for that engine.
2Position0.00–1.00Centers the active source window. Near either end, the window is clamped so it never extends beyond the sample.
3Field0.02–1.00Sets the active window width as a fraction of the sample. The waveform uses a short top tick for Position and a short bottom tick for Field.
4Speed0.05–4.00×Sets base source transport. Pad pitch multiplies it around Root; Grains and Cutups apply that relationship differently, as described in their guides.
5Stack Start1.00–4.00Sets an exact lane/crossfade for Manual stack motion, or the starting phase of a moving stack path. Direct Sample and Slices round it to a discrete loaded lane.
6Scan Rate0.125–16 HzSets cycles per second for moving stack paths. Loop freezes the audible phase. Direct Sample, Slices, and Cutups do not use continuous stack scanning.
7Join0.00–1.00Scales seam smoothing for continuous/event readers. Motion also uses it as articulation depth. Cutups has a separate Cut Join for event-to-event fades.
8Level0.00–2.00Final instrument output gain. Pad velocity never attenuates playback.

Context matters: the shared page keeps the same knob layout for every engine, but some controls affect only particular playback methods. Each engine guide states which controls apply.

What every engine shares

All engines can play up to eight voices from the four sources owned by the current performance clip. Each voice has its own pitch, read position, release, and physical pad assignment. Motion, Lanes, and Grains also give every voice its own movement through the stack; Cutups, Sample, and Slices choose discrete lanes.

The later Mix / Rec, Sample Edit, Performance Loop, Overdub Takes, and Chain pages are available after every engine's contextual pages. Their controls are covered in Samples and Recording and Performance Loops.
