Sound layer

Playback engines

Fifteen engines reinterpret the same four stereo lanes. Start here to compare them, then open an engine guide for every parameter, option, range, and interaction on its contextual pages.

The right-aligned title fraction shows the page’s position within its current bank. Engine pages belong to Voice, so their total changes with the selected algorithm: Sample has the shortest Voice bank, while Grains and the extended Motion modes add contextual pages. Lane, Mix/FX, Performance, Setup, and MIDI use their own local counts rather than one global page total.

Instrument modes: Single, Split, Shared Dual, and Quad use different lane layouts and voice budgets. Compare the modes and choose a layout before following the controls below.

Shared Pads & Scale page

This page follows Engine for every playback algorithm. It chooses what the 32 pads do and, in Keys mode, whether they use the original chromatic layout or a folded scale layout.

Legato changes pitch while keys overlap, preserving playback position, stack phase, envelope and the first engine assignment. The newest held key has priority; release it to return to the previous key.

Storing a cue also remembers the owning part's latest playhead lane/blend. Recall holds that blend and aligns the Stack Start value with it. Turn Stack Start to move the held blend; this leaves the stored cue unchanged. Loop resumes the scan. Delete + cue pad clears it. Cues saved by older releases remain time-only until stored again.

Named scales retain an overlapping isomorphic shape: each row begins three scale degrees above the row below. Up/Down moves the complete layout by octaves. Scale affects the Move pads only; external MIDI and notes already stored in a performance clip are not quantized or rewritten.

Open Capture + Menu → Voice → Play Gain and use knob 1, COMP. This is the gain compensation previously labeled POLY. Polyphony Compensation adjusts summed energy as simultaneous voices and Rolls increase. It is global and separate from VOICE’s Poly, Mono and Legato choices.

Engine List: different engines in one chord

On Pads & Scale, set ENGS to LIST. The Voice Engines and Voice Setup pages appear immediately after it. Each encoder assigns an algorithm to one entry: eight in Single, four per part in Split or Shared Dual, and two per part in Quad. Unavailable entries show reserved boxes. Each part keeps its own list and order.

KnobDisplayRangeWhat it controls
1–8E1–E815 enginesAlgorithm for that list entry. Only entries within the part's voice budget are available.
Main encoderUnderlineAvailable entriesTurn to choose the entry whose engine pages you want to edit; click to open them. Their titles show E1, E2, and so on.

UP chooses the lowest free entry; DOWN chooses the highest. RAND chooses uniformly among the currently free entries. With all four entries free, Grains, Grains, Sample, Weave gives Grains a 50% chance and each other engine 25%. Holding a note removes its entry from subsequent Touch choices until note-off. Keyboard assignments can give more than one note the same entry.

Each note keeps its assigned engine through its release, even if you edit that entry. Note-off makes the list entry available again while its old tail continues where voice capacity permits. The total remains eight source voices: four per part in either dual mode or two per part in Quad. Normal voice stealing and its fade safeguards still apply. Rolls capture the active audio rather than choosing a new source engine.

Click into an entry to use the existing engine pages. Changing ALG there changes that entry. Entries using the same engine share that part's engine-specific controls. Voice Setup adds four independent offsets for each entry; these are captured by new notes, rather than changing notes already sounding. Position, Field, stack controls, envelope, scale, sources and effects also remain shared within the part. The waveform header shows LIST or LST, and each playhead uses its actual engine's cursor behavior. Playhead LED colors continue to identify physical voices.

Lists, order and selected edit entry save with clips and follow part/clip copies. Performance recording stores the resolved engine, list entry and four entry offsets of each note, including notes held before recording starts. RAND therefore replays the captured choices. Changing a list does not rewrite recorded note assignments; record a new performance to capture a different distribution. Returning ENGS to ONE applies the edited algorithm to new live notes; already active notes retain their assignments.

Use Move to set up the list. ALG on the E16 Remote Engine page edits the selected entry's algorithm for each part. E16’s engine-specific pages edit the selected entry’s parameters. For a custom controller, use the Engine List NRPN addresses.

Play engines by keyboard position

Degree and Register assignment give notes consistent engine roles. Assignment follows note pitch, so overlapping pads that play the same note select the same entry. Each part can use its own assignment.

  1. In a multi-part mode, tap Capture to focus the part you want to set up. Press Menu and open Pads & Scale.
  2. Set knob 1, PADS, to KEYS, and knob 7, ENGS, to LIST. Choose Root and Scale with knobs 2 and 3.
  3. Open the next page, Voice Engines. Assign an engine to each available entry with its corresponding knob: eight entries in Single, four per part in either dual mode, or two per part in Quad.
  4. Open Voice Setup. Turn knob 2, ASSN, to DEGR or REG.
  5. Press Menu to return to the waveform and play. The same note selects the same entry regardless of playing order or which other notes are held.

DEGR — scale degree: with C Major in Single mode, C selects E1, D selects E2, E selects E3, and so on through B at E7. C in another octave returns to E1. Assign Sample to E1, Grains to E2 and Weave to E3 to hear the first three degrees use those engines. When a part has fewer entries than scale degrees, the mapping wraps through its available entries.

REG — register: the part’s current keyboard pitch range is divided into bands across its available entries. Lower notes select earlier entries and higher notes select later entries. The bands follow the keyboard octave and scale layout. Incoming MIDI notes beyond that range select its first or last entry.

Several notes can use the same entry while keeping separate playheads within the part’s voice budget. ORDR becomes reserved during Degree or Register assignment. Choose TOUCH on Voice Setup to use Up, Down, Random, Cycle or Shuffle again. Use EDIT on Voice Setup to choose an entry before adjusting its octave, source start, stack offset or pan; those offsets apply after engine assignment.

Pressure expression

Choose PRES on Pads & Scale. Pressure affects each pressed note independently and never uses strike velocity as a volume control. DPTH is on that page in One mode, or on Voice Setup in List mode. Choose pressure mode and depth before recording: they save with the clip as setup, while the pressure gestures themselves are recorded.

Character and Voice Setup: PRES chooses the pressure behavior for the whole part. With CHAR selected, every pressed note uses its assigned engine’s character treatment. Voice Setup’s EDIT selection chooses the entry whose settings you are editing; pressure expression follows each played note. DPTH sets the strength for all notes in that part.

Character is per-voice modulation: engine pages and MIDI feedback continue to show the saved base settings. Quad offers OFF and CHAR because its parts do not have a multi-lane scan to offset or brake. Move polyphonic pressure and external MIDI polyphonic aftertouch are supported. The recorder includes pressure already held when recording starts and captures later MIDI pressure by note and part. Recorded engine choices and entry offsets remain fixed; pressure continues to shape each replayed voice.

Shared Amp Envelope page

Amp Envelope follows Pads & Scale, or Voice Engines when LIST is enabled, for every playback algorithm. It shapes the amplitude of each of the eight source voices independently after that voice's playback engine. Pad velocity does not change amplitude.

KnobDisplayRangeWhat it controls
1ATK0 ms–10 sAttack time from silence or the current retrigger level to full amplitude.
2DEC0 ms–10 sDecay time from the attack peak to Sustain. Values below 1 ms retain a 1 ms safety ramp when Sustain is below the attack peak.
3SUS0–100%Sustain level held while the pad, latch, or recorded note remains on.
4REL0 ms–20 sRelease time from the current level to silence after note-off. The 0 ms setting retains a transparent 3 ms safety taper.
5–8Reserved—Inactive positions available for future envelope controls.

The time knobs use close-spaced millisecond values near zero and progressively wider steps for long fades. The default 3 ms attack, 0 ms decay, 100% sustain, and 25 ms release preserves the earlier immediate pad response while suppressing clicks. Replaying a note during a long release leaves its old tail on a separate voice when capacity permits; when the available voices are occupied (eight in Single, four per part in Split), the reused voice fades out before its reader restarts. Envelope gestures recorded into a performance clip replay with that clip. Rolls use a captured, already-enveloped stereo fragment and retain their separate short edge crossfade; the Amp Envelope is not applied a second time.

Roll fragment length follows its division and the BPM at capture. Stack Start and Scan Rate remain on Engine and are not repeated here. Quad omits this page because each part owns one lane. Its discrete VARI control also stays on that assigned source.

Editable stack paths

On Stack Path, turn PATH to DRAW, then click the main encoder to open Path Editor. You can also reach it inside the Voice bank with Capture + Track 1 or Capture + Menu → Voice. It appears only while DRAW is selected.

KnobDisplayRangeWhat it controls
1PT1–point countSelected breakpoint. Its time, lane, and outgoing curve appear under knobs 2–4.
2TIME0–99%Point time within one cycle. The first point stays at 0%. Other points stay ordered, at least 1% apart.
3LANE1.00–4.00, or the owning pairLane position, including blends. Split B shows physical lanes 3–4. Repeated lane values at adjacent points make a pause.
4CURV−100–100Curve from this point to the next. Zero is linear; positive values start slowly and accelerate; negative values start quickly and slow down. The last point controls the return to the first.
5PNTS4–8Point count. Turning up inserts after the selected point while preserving the existing curve. Turning down removes the selected point; if the first point is selected, it removes the last instead.
6–7Reserved—Inactive positions, shown by hollow boxes.
8RSETShift + turn clockwiseRestore the four-point triangle. The curved-arrow Undo key can restore the previous edit.

To make a pause, give two adjacent points the same LANE value and separate their TIME values. Playback continues within the held lane. To revisit a layer, use its LANE value again later. Uneven times change travel speed between visits. If a segment is too short to add another point, choose a different point or move its neighbors apart.

Scan Rate on Engine or the waveform page sets the cycle speed; point times are percentages of that cycle. OFST rotates the route. SLEW smooths audible transitions, so very short pauses at a fast rate may be softened. Back returns to Stack Path.

All voices in a part use the same authored shape with their own existing phases. Editing the shape keeps those phases running. Motion packets, Grains, and Weave follow live edits without restarting their events. Glitch reads new source positions when its buffer refreshes. Loop freezes travel; recalled cues and Capture lane grabs retain their explicit lane positions until released.

Paths are stored per clip and per part. Single uses four lanes; Shared Dual has independent A/B paths over all four; Split maps each path across its owning pair. Quad, Sample, Slices, and Cutups do not show this editor. Switching to a named path leaves the authored points available when you return to DRAW.

Record captures point and curve edits as performance data. Replace and Overdub keep their usual behavior, and Undo Take removes the path edits made in that take.

What every engine shares

Single shares eight voices across the clip’s four lanes. Split gives each instrument four voices across its own two lanes; Shared Dual gives each four voices across the same four sources, using the same or different engines with independent settings. Quad gives each of four parts one lane and two voices. Each voice has its own pitch, read position, release, and physical pad assignment. Motion, Lanes, Grains, Glitch, Weave, and Wavesets also give every voice its own movement through the stack; Cutups advances each voice’s discrete lane after a chosen number of cuts. Sample and Slices choose discrete lanes. Their lane activity bars follow the actual readers: the latest held voice in Single, or combined voice activity in Split, Shared Dual and Quad. Each playhead’s square marks that voice’s source lane.
