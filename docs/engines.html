The shared Engine page

KnobDisplayRangeWhat it controls
1ALG6 choicesAlgorithm selects Motion, Lanes, Grains, Cutups, Sample, or Slices. Up/Down then shows the pages for that engine.
2POS0.00–1.00Position centers the active source window. Near either end, the window is clamped so it never extends beyond the sample.
3FLD0.02–1.00Field sets the active window width as a fraction of the sample. The waveform uses a short top tick for Position and a short bottom tick for Field.
4SPD0.05–4.00×Speed sets base source transport. Pad pitch multiplies it around Root; Grains and Cutups apply that relationship differently, as described in their guides.
5STAK1.00–4.00Stack Start sets an exact lane/crossfade for Manual stack motion, or the starting phase of a moving stack path. Sample and Slices round it to a discrete loaded lane.
6RATE0.125–16 HzScan Rate sets cycles per second for moving stack paths. Loop freezes the audible phase. Sample, Slices, and Cutups do not use continuous stack scanning.
7JOIN0.00–1.00Join scales seam smoothing for continuous/event readers. Motion also uses it as articulation depth. Cutups has a separate Cut Join for event-to-event fades.
8LEVL0.00–2.00Level sets final instrument output gain. Pad velocity never attenuates playback.

One control, one location: a parameter appears on only one parameter page. Shared pages retain the same knob positions wherever they appear. A small hollow box marks an unassigned encoder position reserved for a future control; turning that encoder does nothing.

Shared Stack Path page

Motion, Lanes, and Grains all use this same page to shape movement through the four audio lanes. Stack Start and Scan Rate remain on Engine and are not repeated here.

KnobDisplayRangeWhat it controls
1PATH8 choicesChooses Down, Up, Triangle, Sine, Steps Down, Steps Up, Manual, or Random movement through the stack.
2BLNDCrossfade / JumpCrossfade blends adjacent loaded lanes; Jump selects the nearer loaded lane.
3SHAPLinear / Smooth / Exponential / PlateauChanges the contour of the path before it becomes a lane position.
4OFST0.00–1.00Rotates the path through one complete cycle without changing Scan Rate.
5SKEW0.02–0.98Moves the path's halfway point earlier or later in the cycle.
6CURV−1.00–1.00Bends travel toward a faster start or a faster finish.
7SLEW0–500 msSoftens abrupt lane-weight changes, especially with Jump and stepped paths.
8Reserved—Inactive and available for a future Stack Path control.

Shared Direct Play page

Sample and Slices use this same page for playback direction, lane selection, and pad behavior. Position, Field, Speed, Stack Start, and Level remain on Engine.

KnobDisplayRangeWhat it controls
1PLAYForward / Reverse / Loop / Ping PongChooses direction and whether the window or slice stops or repeats.
2VARIManual / Cycle / Random / No Repeat / VelocitySelects a discrete lane whenever a voice begins.
3PADSKeys / Slices / Cues / RollsChooses how the 32 pads address pitch, regions, cues, or rolls.

What every engine shares

All engines can play up to eight voices from the four sources owned by the current performance clip. Each voice has its own pitch, read position, release, and physical pad assignment. Motion, Lanes, and Grains also give every voice its own movement through the stack; Cutups, Sample, and Slices choose discrete lanes.

The later Mix / Rec, Sample Edit, Performance Loop, Overdub Takes, and Chain pages are available after every engine's contextual pages. Their controls are covered in Samples and Recording and Performance Loops.
