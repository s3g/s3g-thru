Sound layer

Playback engines

Six engines reinterpret the same four-lane source bank. The page list changes with Algorithm so controls from unrelated engines never occupy the surface.

Shared controls

ControlBehavior
PositionCenters the source region used by continuous, grain, and event readers.
FieldSets the width around Position. Smaller values constrain playback to a tighter region.
SpeedSets source transport rate. Notes transpose around Root; the precise relationship depends on the engine.
Stack StartManual lane/crossfade position, or the initial phase offset for a moving stack path.
Scan RateSets moving stack cycles per second. It does not erase Stack Start; it advances from that offset.
JoinSmooths loop seams, direction changes, packet edges, and other engine transitions.
LevelFinal gain. Pad velocity is deliberately not a playback gain control.

Each of the eight voices owns its own read phase and stack phase. Press Loop to hold every current stack phase—including between-lane crossfades—without pausing the sample read heads or performance loop.

Motion

Motion treats Position inside Field as a performed trajectory. Notes retune source travel; Sound adds an articulation without replacing the chosen path.

Motion modePath
Forward / ReverseOne-way reading through the Field with a smoothed wrap.
HoverRegular smooth return motion.
Round TripForward/backward traversal without polarity inversion.
Moving LoopA loop window that advances through the source.
MirrorForward/backward travel with the Sample Motion mirror behavior.
ZigzagAlternating forward and backward segments using Travel and Jitter.
DrunkDeterministic random targets within Field.

Motion Path provides Mode, Travel, Jitter, Position, Field, Speed, Join, and Level. Motion Sound selects Continuous, Packets, Motor, or Bounce and adds Gesture Rate, Packet Duty, Motor Rate, Motor Symmetry, and Motor Shape. Bounce is a bounded hardware articulation, not the desktop Motion segment-event router.

Lanes

Lanes Mode selects Forward, Reverse, or Ping Pong reading. Stack Path selects Down, Up, Triangle, Sine, Steps Down, Steps Up, Manual, or deterministic Random movement. Transition chooses continuous Crossfade or discrete Jump. Path Shape changes the curve to Linear, Smooth, Exponential, or Plateau.

The Lanes Shape page adds path Offset, Skew, Curve, Jump Slew, Stretch, Stretch Ratio, Speed, and Level. Stretch compensates different lane lengths relative to the reference lane; turn it off when different durations should deliberately run at their own rate.

Grains

PageControls and purpose
Grains MainMode (Scan, Freeze, Cloud, Slice), Size, Density, independent Grain Pitch, six windows, Stereo Spread, Position, and Field.
Grains CloudPosition Spray, directional Bias, Pitch Spray, Reverse chance, Size/Level variation, Timing mode, and Timing Scatter.
Grains ProcessOrdinary, Stutter, Shrink, or Doublets; amount, envelope skew, regions, Scan/Per Grain advance, Quality, Stack Path, and Scan Rate.

Quality limits each playback voice to 4, 8, or 16 active grains. Eight is the intended starting point on Move. Use four if the Help screen's deadline-overrun count rises; sixteen is a stress option, not a guaranteed default.

Keyboard pitch changes source advance while Grain Pitch remains an independent timbral ratio. This makes it possible to change cloud motion and grain transposition separately.

Cutups

Cutups chooses discrete regions and lane sources at event boundaries. The Clock page selects Free or Tempo timing, division, free rate, timing variation, gate, cut join, region count, and Equal/Transients region source. The Path page adds repeats, reverse chance, pitch and level variation, seven lane orders, four polyphonic paths, region count, and Field.

Tempo divisions are 1/4, 1/8, 1/8T, 1/16, 1/16T, and 1/32. Cut note pitch retunes each region reader while the event clock stays at its free rate or tempo division. A cut chooses a discrete lane; it does not read the continuously crossfaded Lanes mix.

Sample and Slices

Sample plays a complete lane Forward, Reverse, Loop, or Ping Pong. Slices uses the same playback modes but maps pads to Equal or automatically detected Transient regions. Equal Slice Count ranges from 1 to 64.

Lane Variation selects Manual, Cycle, Random, No Repeat, or Velocity. In these direct/discrete engines, Velocity can choose a lane variation but still does not control output amplitude.

Pad modes

ModePad behavior
KeysIsomorphic chromatic note grid. Up/Down transposes by octave.
SlicesThe 32 pads address source regions while the root pitch remains fixed.
CuesPads 1–8 jump to cues. Shift+pad stores the displayed playhead; Delete+pad clears it.
RollsHeld pads become tempo-divided Cutups voices, one division per pad position.

Pages shared by every engine

  • Mix / Rec: four lane gains, Input/Resample source, Record Gain, Monitor, and Preview Level.
  • Sample Edit: Trim Start/End, Trim Apply, Reverse, Normalize, Edge Fade, Record Gain, and Level.
  • Performance Loop: rate, timing, launch quantize, BPM, Replace/Overdub, swing, pressure behavior, and Root.
  • Overdub Takes: recording mode and Undo Take, with take count in the title.
  • Chain: enable, edit slot, clip, repeats, clear, Algorithm, Join, and Level.
