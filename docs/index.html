s3g Thru

A stereo sample instrument with four audio lanes and eight independent voices. Play them as one stack, or divide the pads into two instruments in Split mode. A performance recorder captures notes, pressure, stack holds, and parameter motion as loopable data.

s3g Thru is an adaptation and extension of the s3g-dsp Sample family, rebuilt around Move’s pads, controls, display, live input, and performance workflow.

manual · 0.28 testing build

This manual includes features in 0.28.0-test.13. The installed version appears briefly when takeover opens. See GitHub releases for published downloads and release notes; use the matching local testing tarball to try features not yet in a public release.

Split mode: two independent instruments share the pad grid, with two stereo lanes and four voices each. Use the same engine with different settings or choose different engines. Split setup, controls, mixing, and recording.

New in the 0.28 testing build

  • Split mode gives A and B independent engines, keyboard settings, envelopes, and private inserts, with a continuous Blend between them.
  • Waveform zoom enlarges the active source window in both modes. Split keeps independent windows, shows cursors over their own lane pair, and highlights lane numbers to identify editing focus.
  • Plate and Room reverb and FX Order extend the effects. Split adds shared Delay/Reverb sends and returns, with a direct FX Pages menu.
  • Live Split mixing lets you override recorded Blend, levels, sends, and Curve until playback restarts or another clip launches. Record an overdub to keep the new gestures.

Quick start

  1. Install Schwung 1.7.3 or newer. In Schwung Manager, choose Install Custom Module → GitHub URL, enter https://github.com/s3g/s3g-thru, and restart Move when prompted.
  2. On Move, hold Shift, touch the master-volume knob, then jog-click to open Overtake. Choose s3g Thru.
  3. Use headphones. Select Move's microphone or line input and set its hardware input gain before recording.
  4. Press Track 1–4 to select a lane. Hold Shift and press Record to start and stop stereo audio capture.
  5. Press pads to play. Pad pressure moves that voice through the lane stack; velocity does not change sample volume.
  6. Press Menu for parameters. The eight screen cells correspond directly to the eight encoders.
  7. Press Record without Shift to capture a free-time performance-data loop. Press it again to close the loop.

Feedback safety: input monitoring defaults to zero. Keep speakers down or use headphones when a microphone is selected. Increase Monitor only when direct pass-through is intentional.

The three-layer mental model

1 · Four audio lanes

Each lane holds a stereo recording or a WAV from Move's sample library. A clip owns its four source assignments.

2 · Eight voices

Every note has its own playback head, pitch, envelope, stack phase, and pressure offset. Single shares eight voices; Split assigns four to A and four to B.

3 · Sixty-four clips

A01–D16 store source assignments, engine settings, notes, pressure curves, knob gestures, and undoable overdub takes.
