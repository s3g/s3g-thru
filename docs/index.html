Ableton Move · Schwung takeover

s3g Thru

A stereo sample instrument with four audio lanes and eight independent voices. Play them as one stack, two independently configured instruments, or four instruments in Quad mode. A performance recorder captures notes, pressure, stack holds, and parameter motion as loopable data.

s3g Thru is an adaptation and extension of the s3g-dsp Sample family, rebuilt around Move’s pads, controls, display, live input, and performance workflow.

manual · 0.28.0

This manual describes s3g Thru 0.28.0. The installed version appears briefly when takeover opens. See GitHub releases for published downloads and release notes.

Known issue in 0.28.0: Shift + Capture conflicts with Schwung Skipback. Use Capture + Menu → FX SENDS instead. A future release is planned to change Thru’s shortcut; see Known issues.

Choose Single, Split, Shared Dual, or Quad for different source layouts and voice budgets. All use the same four stereo source lanes and performance recorder.

New in 0.28.0

  • Split and Shared Dual combine two independent engines; Quad provides four instruments with independent programs, levels, mutes, and sends.
  • Plate and Room reverb add stereo space. FX Order lets you lift and move effect blocks in a readable list.
  • Cutups Lane and Advance put source changes under direct control, with overlapping joins and visible outgoing readers.
  • Waveform zoom follows the source window. Shared Dual and Quad keep live POS/FLD editing responsive while notes play.
  • Pages, Panic, the curved-arrow Undo key, Part/Direct preview, and activity/save readouts make playing and editing easier to follow.

Quick start · Single mode

These first steps use Single, the default four-lane instrument. A saved clip can recall another mode; choose Single from Capture + Menu → Instrument Mode when following the Basic Playing guide.

  1. Install Schwung 1.7.3 or newer. In Schwung Manager, choose Install Custom Module → GitHub URL, enter https://github.com/s3g/s3g-thru, and restart Move when prompted.
  2. On Move, hold Shift, touch the master-volume knob, then jog-click to open Overtake. Choose s3g Thru.
  3. Use headphones. Select Move's microphone or line input and set its hardware input gain before recording.
  4. Press Track 1–4 to select a lane. Hold Shift and press Record to start and stop stereo audio capture.
  5. Press pads to play. In engines with stack motion, pressure offsets that voice’s lane position. Quad stays on one lane per part. Velocity does not change sample volume.
  6. Press Menu for parameters. The eight screen cells correspond directly to the eight encoders.
  7. Press Record without Shift to capture a free-time performance-data loop. Press it again to close the loop.

Feedback safety: input monitoring defaults to zero. Keep speakers down or use headphones when a microphone is selected. Increase Monitor only when direct pass-through is intentional.

The three-layer mental model

1 · Four audio lanes

Each lane holds a stereo recording or a WAV from Move's sample library. A clip owns its four source assignments.

2 · Eight voices

Every note has its own playback head, pitch, envelope, stack phase, and pressure offset. Single shares eight voices, Split and Shared Dual assign four to each part, and Quad assigns two to each of four parts.

3 · Sixty-four clips

A01–D16 store source assignments, engine settings, notes, pressure curves, knob gestures, and undoable overdub takes.
