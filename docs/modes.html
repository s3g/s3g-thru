Source layout · voice budget · editing focus

Instrument modes

Use all 32 pads as one instrument, play two independent programs, or divide the grid into four instruments. Every mode uses the same four stereo source lanes and the same eight-source-voice budget.

Choose a mode

  1. Hold Capture and press Menu to open Pages.
  2. Choose Instrument Mode and click the main encoder.
  3. Turn or use Up/Down to select Single, Split, Shared Dual, or Quad. Click to apply; Back returns to Pages.

The star marks the active mode; the highlight marks your selection. Finish audio and performance recording before changing mode. Applying a mode stops the data loop and releases the current notes through their transition fades. Outside the clip and chain editors, Copy switches between Single and your last selected multi-instrument mode.

Every part has its own engine, note pitch, keyboard settings, envelope, and private effects. Two parts may use the same engine with different settings. Eight is the source-voice total, not eight per part; a release tail still occupies its voice slot. Rolls use captured stereo history and do not steal source voices.

Focus and source selection

In multi-instrument modes, Capture changes which program the parameter pages edit. Playing another zone keeps the current focus. Dual modes alternate A/B; Quad cycles A–D. Each part remembers its parameter page.

Track 1–4 always selects a lane for recording, loading, and sample editing. Split also focuses that lane’s owning side, and Quad focuses its corresponding A–D part. Shared Dual keeps source selection separate from focus because both programs can use every lane.

Split B’s idle pads are muted teal, Shared Dual B’s are muted plum, and Quad zones use neutral grey, teal, amber, and plum. Scale roots brighten the zone color. Active playheads, held notes, Cues, and Rolls retain their status colors.

Waveform windows

POS moves a source window and FLD changes its width. In Single, one window fills all four rows. Split shows independent windows over its two lane pairs. Those views can widen to include sounding readers and release tails.

Shared Dual shows all four sources through the focused instrument’s editable POS/FLD window. Quad gives each lane row its own part’s editable window. These views remain responsive while notes or a data loop play; readers outside the window are hidden while their audio continues.

Levels and effects

Single uses the complete configurable effects chain. In both dual modes, waveform knob 8 is BLND; part levels remain on their Engine pages. Capture + knob 8 reaches Blend from any page. Quad uses LEVL for the focused part on waveform knob 8 and the same Capture shortcut.

Multi-instrument modes give every part private Color and Stereo / Rotary inserts. Open FX Sends with Capture + Menu → FX SENDS. Dual modes keep returns on that sends page; Quad uses all eight positions for sends and puts DRTN/RRTN on knob 8 of Delay Return/Reverb. Delay and Reverb remain parallel sends, with Tape shared according to FX Order. Read the complete dual-mode mixing or Quad mixing instructions.

A/B Mix Status

In Split or Shared Dual, open Capture + Menu → A/B Mix Status. Each meter follows that part’s inserts, level, mute, and Blend. Voice counts include release tails, up to four per part. Shared effect tails and sample preview are excluded; Rolls can produce activity without increasing the source-voice count. Capture changes editing focus, and Menu or Back returns to waveforms.

DisplayMeaning
ACTIVEA source voice or Roll is active; the meter shows its actual audio level.

NO AUDIOThe part’s two source lanes are empty in Split, or all four shared lanes are empty in Shared Dual.
IDLEThe part has source audio but no active voice or Roll.

Quad provides a four-part Mix Status view with the same activity and silence indicators.

Dual Setup

Split and Shared Dual use the same setup controls. Choose the page from Capture + Menu → Dual Setup. Quad has its own Quad Setup.

KnobDisplayRangeWhat it controls
1MODESingle / Split / Shared / QuadInstrument mode selects Single, Split, Shared Dual, or Quad. Stop audio and performance recording before changing mode.
2EDITA / BEdit changes the side controlled by the parameter pages.
3COPYTurn to applyCopy duplicates the focused side’s engine, pad, envelope, lane-gain and insert settings to the other side. Samples, cues, recorded notes, the destination’s mute state, shared returns, and Blend stay in place.
4MUTEOff / OnMute fades out the focused side.

Shift + Copy performs the same settings copy directly. After copying, edit the other side to vary its sound while keeping the same engine.

Recording and recall

Each clip stores its mode, programs, source assignments, recorded notes, and automation. The performance recorder captures all active parts together. Audio recording still captures one selected source lane at a time. Shared Dual programs read the same audio: replacing or editing a shared lane changes that source for both.

Single remembers a separate program. A/B sound settings are shared between the multi-instrument layouts; C/D programs and recorded notes remain stored when you select a two-part mode. C/D notes are silent in the two-part layouts and become available again in Quad.

Before upgrading: export a set backup using the backup instructions. The current bank format requires s3g Thru 0.29.0 or newer. Keep an older export if you need to downgrade.

Use the shortcuts reference for the full control map, and External MIDI for part channels and Quad’s channel-specific mixing CCs.
