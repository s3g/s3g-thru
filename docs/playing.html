Basic playing · Single mode

Basic playing

Start with one four-lane stereo instrument. All 32 pads play the same program, with eight independent source voices and one complete effects chain.

Start with Single

Single is the basic playing mode: the whole pad grid controls one program over four stereo lanes. Saved clips can recall another mode. To return to Single, hold Capture and press Menu, choose Instrument Mode, select Single, and click the main encoder. Finish recording before changing mode.

The Track keys choose a source lane for recording, loading, and editing. They do not turn the four lanes into separate instruments: the selected playback engine determines which lanes each note reads.

Load or record a sound

  1. Press Track 1–4 to choose the destination lane.
  2. To load a WAV, hold Shift and press that Track key. Turn the main encoder to browse; click to enter a folder or load the selected file. Highlighted files audition at Preview Level.
  3. To record instead, choose Move’s microphone or line input and set its input gain, then use Shift + Record to start and stop a stereo capture. The finished recording becomes the selected lane’s source.
  4. Repeat for the other lanes you want to use. A scanning engine can become quiet when it reaches an empty lane.

Use headphones when recording the microphone. Leave Input Monitor at zero unless direct monitoring is intentional. See Samples and recording for input setup, library browsing, saved recordings, and source ownership.

Play notes

In the Keys pad mode, press pads to play pitches. Up/Down changes the keyboard octave. Choose Root and Scale on Pads & Scale to change the available notes. Root-pad colors identify tonics; an active note uses its playhead color. Pad strike velocity does not set sample volume.

Each note has its own voice and path through the source stack. Higher notes transpose the source according to the chosen engine; grains and time-based processing can change duration independently of pitch. A long release still occupies a voice slot. Use the engine guides to choose direct Sample playback, moving stacks, grains, cuts, or other treatments.

Press Menu to open parameter pages. The eight encoders match the eight screen positions. Use Up/Down to change parameter pages, or Capture + Menu to choose a page directly. The Engine, Pads & Scale, and Amp Envelope references explain the shared controls.

Shape the source and stack movement

On the waveform page, POS moves the source window and FLD changes its width. The display enlarges that region across all four rows. SPD sets the base transport rate; note pitch remains an additional transposition. See the waveform control map for the eight encoders.

For engines with stack motion, Stack Start seeds a new voice’s lane position and Scan Rate advances it along the selected path. Pressure offsets that voice’s position. With a Manual path, Stack Start selects the exact lane blend. Press Loop to hold the audible stack positions, including blends between lanes; press again to resume.

Controls adapt to the engine. Cutups uses Lane and Advance for discrete source changes; Sample and Slices use their Direct Play settings. The engine guide explains these differences.

Hold and release notes

A normal pad press is momentary. Shift + pad toggles that note’s latch; repeat to release it. Pads & Scale’s Hold Off can keep latches until toggled, or release them after a chosen delay. Amp Envelope sets attack, decay, sustain, and release.

Hold Delete and press Play for Panic: stop the performance loop and release notes, latches, Rolls, and preview. Existing effect tails decay naturally. See held notes and Panic.

Set level and effects

Single sends the instrument through the complete effects chain. Use Level for the instrument’s playback level and Mix / Rec’s lane gains to balance sources. Record Gain affects new audio recordings. FX Order changes the series of effects; each effect has its own parameter page.

Capture a performance

Press Record without Shift to record notes, pressure, stack holds, and parameter movements as data. Notes already held are included. Press Record again to finish, and use Play to start or stop the loop. Step keys select stored clips rather than individual note steps. The Performance loops chapter covers Replace, Overdub, takes, clip banks, and chains.

When you want more than one independently configured instrument, compare Split, Shared Dual, and Quad. They keep the same sources and performance recorder while dividing the eight source voices differently.
