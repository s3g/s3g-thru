Audio layer

Samples and recording

Each performance clip owns four audio lanes. A lane can be a stereo live capture, a stereo resample of Thru's output, a WAV in Move's User Library, or intentionally empty.

Recordings are archived and waveform/transient analysis finishes in the background while playback continues. If you start another audio take before the previous archive is ready, the new take waits and starts automatically once that recording is safely stored. Loading or editing a lane may briefly wait for its archive. Settings save after controls settle; leave takeover normally before powering off so the latest changes can finish saving.

Audio signal flow

Sources

Each clip owns four assignments chosen from live recordings, resamples, library WAVs, archived Thru recordings, or Empty.

Playback

Single reads the four lanes with up to eight voices. Split assigns lanes 1–2 and four voices to A, lanes 3–4 and four voices to B, with private inserts and shared returns.

Monitoring

Input Monitor bypasses the sampler and effects, then joins the final safety limiter. It is dry and defaults to zero to reduce feedback risk.

Set the input safely

  1. Use Move's stock sampling controls to select microphone or line input and set the hardware input gain.
  2. Connect headphones before using the microphone near speakers.
  3. Open Thru's Mix / Rec page and leave MON at 0.00 unless you deliberately need direct monitoring.
  4. Start with REC GAIN at 1.00. The display reports LIM if the stereo-linked −1 dBFS capture limiter reduces the stored signal. Lower Record Gain if LIM appears frequently.

Quiet playback is not corrected with Record Gain. Record Gain affects newly captured audio. Use the lane gains and Level for playback balance. In Split also check the focused part’s LEVL, Mute, and Blend; see Restore a silent part. Normalize is an explicit destructive sample edit.

Record or replace a lane

  1. Press Track 1, 2, 3, or 4 to select the destination.
  2. On Mix / Rec, choose INPUT for Move's selected hardware input or RESAMPLE for Thru's stereo output.
  3. Hold Shift and press Record. The Record key is orange during audio capture.
  4. Repeat Shift + Record to stop. The completed capture becomes that lane's active source; the other three lanes are unchanged.
  5. Wait briefly if SCANNING WAVEFORM appears. The waveform fills in as the scan completes.

The thin mark at the far left of a waveform row identifies the target lane. In Split, the white backgrounds behind two lane numbers identify editing focus instead. The adjacent lane-weight bar shows playback contribution, not input level. During recording, the horizontal bar near the bottom is the capture level.

Each completed input recording or resample is written as a new stereo WAV. Recording the lane again changes its active assignment but does not overwrite the earlier file. Hold Shift and press Delete to clear the selected lane. The latest capture, clear, library replacement, or sample edit can be reversed once with Shift + Back.

The browser starts with two sources. Move Samples opens /data/UserData/UserLibrary/Samples. Thru Recordings opens the module's capture archive with the newest files first. It accepts mono or stereo PCM 16/24/32-bit and 32-bit-float WAV files. Mono files play from both channels, other sample rates are converted automatically, and material beyond the 12-second lane capacity is truncated.

Sample preview

Highlight a WAV to audition it before loading. Preview Level is knob 8, PREV, on Mix / Rec. Clicking the highlighted file loads it into the chosen lane; recording a new take assigns that capture automatically, without a trip to the browser.

Single preview passes through the complete selected effects chain. Split preview follows the destination part’s LEVL, Mute, and Blend, so select the appropriate Track lane and center Blend when comparing files for both sides. It bypasses private Color and Rotary inserts and does not feed Delay/Reverb sends; shared Tape and the final program compressor/limiter still apply.

Sources belong to clips

The first time a blank A01–D16 clip is selected, it snapshots the four sources then in use. Its source assignments then remain independent; loading a sample in another clip does not change them. A loaded file is stored as a User Library path; a recording becomes a clip-local capture; a reset lane remains explicitly empty.

When a clip needs different sources, the previous clip can continue until all four lanes are ready. This prevents a partial change with lanes from two clips. The footer reports FILE, CAPTURE, EMPTY, LOADING, or MISSING.

Gain staging and output safety

At LEVL 1.00, the instrument path reaches a full nominal output. In Split, the two part levels and Blend feed the combined mastering path. A stereo-linked program compressor adds 3 dB of makeup below its −12 dBFS threshold, then applies a gentle 2:1 ratio above it. This raises quieter detail and controls sustained peaks without changing the stereo image. LEVL values above 1.00 push the program stage harder. Polyphony Compensation is on by default and smoothly controls summed energy as more independent voices or Rolls overlap; it does not change pad velocity behavior.

A separate stereo-linked lookahead limiter remains the final safety stage. Its −1 dBFS ceiling catches transient stack, effect, monitor, and polyphonic peaks without flat-topping them. The program compressor supplies everyday density; persistent limiter reduction still means Lane Gain, Level, effect Drive/feedback, Record Gain, or Input Monitor should be reduced.

Shift + Menu opens the System Report. LIMIT CURRENT is the final limiter's present gain reduction and LIMIT MAX is the largest reduction observed since takeover started; a larger number means more attenuation. The complete report is explained in the Shortcut Reference. Imported WAV files at Move's sample rate are copied directly. Other sample rates use high-quality conversion, while transposed playback uses smoother interpolation to reduce rough high-frequency edges.

Saving, recall, and backup

Thru autosaves changed settings and completed captures, then saves again when Back exits from the main waveform page. It also keeps one recovery copy in case a metadata save is interrupted. Capture WAVs are append-only during normal use: rerecording, editing, clearing, and resetting do not delete older files.

Uninstalling a module may remove its data. Before uninstalling or moving to another Move, export the module data with:

scripts/export-set.sh /path/to/s3g-thru-data Thru-set.tar.gz

The exported archive includes current metadata, recovery files, saved lane WAVs, and every local capture. User Library samples remain external paths and should be backed up separately. Because old captures are retained, storage use grows over time. Export before manually removing unused WAVs; deleting a file still assigned to a clip makes that lane report MISSING.
