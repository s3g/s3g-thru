Shortcut reference

The same control can change meaning by view, but recording gestures remain deliberately distinct: Record captures performance data; Shift+Record captures stereo audio.

Known issues in 0.28.0

Shift + Capture conflicts with Schwung Skipback. Schwung uses this shortcut to save recent audio from its rolling buffer as a WAV. It remains active during takeover, so pressing it can show “Skipback saved” instead of opening Thru’s FX Sends. The conflicting Thru shortcut is planned to change in a future release.

Workaround: in Split, Shared Dual, or Quad, hold Capture and press Menu, choose FX SENDS, then click the main encoder.

Reading the System Report

DisplayWhat it reportsHow to read it
RENDER PEAKLongest audio-block render time since takeover started, in microseconds.Lower leaves more time for the rest of the device. Compare it with WORK PEAK on the next report page; rendering is only part of the work needed for playback.
RENDER MISSESNumber of render calls that exceeded one audio-block period.0 is healthy. If it rises while clicks or gaps occur, reduce costly grain/event settings or active polyphony. This count excludes control and query work.
CONTROL PEAKLongest live parameter or MIDI operation, in microseconds.Watch this while changing controls or playing. A rise helps distinguish control work from engine rendering.
QUERY PEAKLongest display/status query, in microseconds.A large value points to work associated with reading or updating instrument information.
WORK PEAKLargest combined time for rendering and the preceding Thru control/query calls.Compare it with RENDER PEAK to see the additional cost of interaction. It excludes work performed elsewhere in Move or Schwung.
WORK MISSESNumber of combined-work intervals that exceeded one audio-block period.Watch this as well as RENDER MISSES. A rise with no render misses indicates that control/query work contributed to overload. Zero cannot rule out an interruption elsewhere in the device.
LIMIT CURRENTGain reduction being applied by the final stereo safety limiter, in decibels.0.0 dB means no current limiting. Brief low values on peaks are normal; a sustained or large value means the summed level should be reduced.
LIMIT MAXLargest limiter reduction observed since takeover started.Use it as peak history. A large maximum with a near-zero current value describes an earlier transient, not continuous limiting.

Large counts are shortened with M or G suffixes so every value remains visible. The report is diagnostic history for the current takeover session; opening or closing it does not reset the counters. One 128-frame block at 44.1 kHz lasts about 2,902 µs, and Move and Schwung also need part of that time. Neither report measures every cause of a missed device deadline.

Shift + DeleteClear the selected audio lane.

External MIDI

In Single, notes share one instrument. Split and Shared Dual use MIDI channels 1–2 for A/B; Quad uses channels 1–4 for A–D. Other channels address A. Engine parameter CCs follow that channel without moving edit focus.

Quad mixing: CC 13 controls the addressed part’s level, CC 15 its Delay send, and CC 17 its Reverb send. CCs 14, 16, and 18 retain their fixed B assignments. Quad ignores Blend and Curve and stays on one lane per part, so its stack-scan CCs have no lane-selection role.

Shared controls remain global. External/host MIDI accepts notes, note-off, polyphonic aftertouch, All Sound Off (CC 120), and All Notes Off (CC 123). Parameter CC values are 7-bit absolute.

Move and external CCs are handled separately. Move's plain Loop button controls Stack Hold (or Tape transport in Quad when INRT is enabled) and Shift+Loop controls Glitch Buffer Lock, while CC 58 from an external controller clears the selected chain slot. External CC 51 enables monitoring and can cause acoustic feedback.
