# s3g Thru 0.29.0-test.11

Local testing candidate. Entry Fade now lets you select its target directly.

- Knob 3 / SLOT selects chain entries 01–64 without leaving Entry Fade.
- PATT under knob 4 identifies the pattern assigned to that entry, or shows a dash for an empty entry. This is a readout.
- Selecting a slot updates its saved fade settings and the visible step-key page while playback continues.
- Small selector movements accumulate across entry changes for precise adjustment.

The existing TIME, CURVE, LOW, HIGH and MODE positions remain in place. Step keys and Left/Right still select entries and pages.
