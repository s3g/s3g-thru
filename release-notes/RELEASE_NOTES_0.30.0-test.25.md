# s3g Thru 0.30.0-test.25

Local E16 navigation test build. The public GitHub installer remains at 0.29.1.

## E16 Page Jump

- Adds a twelve-page overview so E16 users can open any Remote page directly.
- Press **Shift + encoder 2**, release Shift, then press encoder 1–12 under
  ENGINE, STACK, ENG 1–4, SENDS, COLOR, ROTARY, DELAY, REVERB or TAPE.
- Marks the current page, closes automatically after a selection, and uses
  encoder 16 as Cancel.
- Suppresses parameter turns while the overview is open, preventing edits to
  controls hidden behind the overlay.
- Preserves Shift + turn encoder 1 navigation, Quad pair switching, Remote
  Exit, fine adjustment and Move's current editing focus.

Install `dist/s3g-thru-module.tar.gz` and the matching script-free THRU RM
scene from `dist/s3g-thru-e16-remote.zip` for hardware testing.
