# s3g Thru 0.30.0-test.40

Local four-bank navigation build. The public GitHub installer remains at
0.29.1.

- Replaces the long first-level Pages list with a compact hub: Voice, Lane,
  Mix/FX and Performance, plus Mode, Setup, MIDI and the complete All list.
- Adds Capture + Track 1–4 as stable shortcuts to the four working banks.
  Repeating the same chord advances through that bank.
- Keeps ordinary Track lane/part selection, Shift + Track sample browsing,
  clip-bank selection, Capture focus taps and Capture + knob 8 unchanged.
- Keeps Up/Down inside the current page bank and labels parameter positions
  with V, L, F or P. Back returns page → bank → hub → the original view.
- Uses Track-key brightness to show page-bank selection while Capture or the
  hub is active, and retains the complete legacy destination list under All.
