# s3g Thru 0.30.0-test.48

Local testing build; not published.

- Bank Sample RATE now sets B’s master speed. Bank Pads RATIO sets each
  sample’s relative speed. Existing recordings keep their previous speed.
- Bank Pads adds smoothed stereo PAN, LOOP / ONE playback, choke groups and
  SRC A / IN. IN records Move’s selected mic/line input with recording
  gain; monitoring is optional. The source is fixed at capture start.

  their sound, and archived recordings remain untouched.
- E16 native relative turns are retained. The attached Thru Rings script
  displays actual values for E16’s page, including Move and Monolit edits,
  resets and recalls. Its read-only refresh cannot overwrite project values.
- In Bank, B ENG 1 follows Bank Sample; B ENG 2 follows Bank Pads.
