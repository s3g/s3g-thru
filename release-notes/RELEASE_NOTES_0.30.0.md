# s3g Thru 0.30.0

New ways to play, record and control Thru, with fifteen sample playback engines
and five instrument layouts.

- **Stochastic and Pulsar:** continuously deform recorded waveforms or build
  pitched pulse trains from sample fragments. Pulsar SIZE reaches 500 ms.
- **Engine Lists and Legato:** assign engines per note, by playing order,
  randomly or by keyboard position. Add voice variations and pressure control,
  or change pitch without restarting a mono playhead.
- **Bank mode:** play a four-lane instrument alongside sixteen persistent stereo
  capture pads, with per-pad playback settings, latch, clear and Undo. Record
  from input, the mix or either part.
- **Portable projects:** export and import clips, chains, settings and referenced
  samples in one `.thru` file through Schwung Manager. Includes sample-recall
  repairs, safer background saves and recovery options for failed Bank takes.
- **Slice editing:** audition, trim, split and merge slices, import WAV markers,
  and adjust transient pre-roll. External MIDI notes can play overlapping slices.
- **Expanded MIDI:** keyboard and sequencer routing, sustain and expression,
  clock following, and Custom CC profiles with MIDI Learn. Updated E16 Remote
  and E16 + Monolit bundles are included with this release.
- **Mixing and navigation:** Priority Duck between parts, aligned Tape dry/wet
  mixing, grouped page shortcuts, clearer page headings and updated manual/help.

Requires **Schwung 1.7.3 or newer**. Keep a backup before updating; older
firmware cannot read the expanded data saved by 0.30.0. Existing recordings
remain available. Fully exit and reopen Thru after importing a project.

See the [manual](https://s3g.github.io/s3g-thru/) for installation, controls,
project backups and controller setup.
