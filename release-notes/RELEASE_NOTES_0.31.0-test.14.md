# s3g Thru 0.31.0-test.14

Local Sequence prototype alongside the recent Layers expansion.

- Sequence mode adds four independent trigger sequences: one sample and engine per lane, two voices per lane, up to 32 steps with independent lengths, rates and rotation.
- Tap to toggle; hold to edit POS, NOTE, VEL, GATE, microtime, probability and up to eight Burst events. Includes waveform markers, scale-aware pitch entry, stopped audition and gate-fitted ADSR.
- Play runs authored trigs immediately. Clips and chains store sequences; repeated clips preserve lane phases. Performance recording captures supported lane and parameter gestures separately from audio recording.
- Browse lanes during an audio take without changing its destination. New audio retains the sequence. Main-pad Copy/Paste/Delete edits trigs; the bottom row remains clip launchers.
- Adds sequencer MIDI destinations and Custom CC support while retaining existing parameter addresses and older projects.
- Includes Layers mode, seventeen parallel corner effects, pressure macros, grouped FX browsing and recent rhythmic-effect smoothing and alias reduction.

Local testing only. The public GitHub installer remains stable 0.30.1.
