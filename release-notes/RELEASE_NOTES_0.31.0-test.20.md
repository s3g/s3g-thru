# s3g Thru 0.31.0-test.20

Local Sequence mixer test build. It is not a GitHub or Schwung catalog release.

- MIX / FX now places SEQ MIX, SEQ STRIP 1–4 and SEQ DUCK consecutively. Use Move Up/Down to move between all four channel strips without returning to the menu or changing the selected sequence lane.
- Each numbered strip page shows and edits that lane's EQ and Solo directly. Opening or changing another strip leaves the audio recording destination unchanged.
- Existing MIDI addresses, clip storage and project format are unchanged. The manual and device help now describe the four strip pages.

All changes from 0.31.0-test.19 remain included. Check the navigation and mixer on Move before release.
