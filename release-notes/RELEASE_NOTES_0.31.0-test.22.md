# s3g Thru 0.31.0-test.22

Local Sequence mute test build. It is not a GitHub or Schwung catalog release.

- Changing a Sequence lane mute while a clip is playing now changes that clip's starting mute state. The change remains when playback stops and starts again.
- Mute gestures captured with performance Record still play at their recorded positions. A manual mute edit keeps later recorded gestures intact.
- The Sequence manual explains how an empty REPLACE take clears recorded notes and gestures while keeping authored trigs.
- The Modes guide now illustrates Bank, Layers and Sequence pad layouts as well as the earlier four layouts. Its mode links and the manual sidebars include all seven modes.
