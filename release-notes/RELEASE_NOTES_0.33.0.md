# s3g Thru 0.33.0

Thru is now a stereo sample and synthesis instrument, with **22 engines: 15 sample engines and seven new realtime synth engines**. This release also adds assignable modulation, broader Sequence sound locks and offline sample processing.

- **TABLE:** clean oscillators, evolving Spline waveforms and punchy WT Drum sounds.
- **SCANNED:** evolving virtual-string tones, plucked and struck sounds, percussive articulation and a dedicated tube/fuzz amp section.
- **FM:** tonal and drum synthesis, four operator routings, independent modulator envelopes, harmonic shaping, routing diagrams and starting sounds.
- **NOISE:** pitched noise bands, dust, crackles, static, clicks, cuts and repeating data textures.
- **RESON:** sustained modal tones and struck percussion, including kick, snare, tom, bell, hat, crash and concert bass, with a dedicated overload circuit.
- **PARTIALS:** additive spectra, harmonic/subharmonic layers and overlapping sound packets, with editable component ratios, levels and dividers.
- **LOWFORM:** bass and lead synthesis combining a centred Foundation, six harmonic bodies, Texture, filtering and overload.
- **Four patches per synth:** blend through stack position and scanning, play polyphonic notes, and view live scopes. The new engines work with the existing modes, Engine Lists, clips, MIDI/E16 and portable projects. Click the main encoder on ENGINE for the full engine picker.
- **Eight assignable Control LFOs:** route any slot to an available part using destinations grouped by familiar pages and full parameter names. Tempo-synced or free rates, run modes, smoothing and AUTO offset keep modulation usable around the saved setting. Supported LFO adjustments can be recorded into clips.
- **Visible modulation and automation:** parameter pages show values moving with LFOs and recorded dial gestures. Markers distinguish the two while manual edits continue to change the saved base value.
- **Expanded Sequence sound locks:** hold a trig and browse engine, envelope, lane mixer and part-effect pages to give that occurrence its own settings. Delete/X + dial restores inheritance. Sound locks support overlapping voices, Burst, copy/paste, Undo and project recall.
- **Process:** Resynth offers spectral and sinusoidal processing with partial-trace controls. Hybrid transfers envelope, spectral colour and pitch traits between selected recordings. Convolve combines a primary sample and an impulse. Render when ready, audition the completed result, name it on Move and save it to the library or a lane. Recipes and source files travel with portable projects.
- **Performance and navigation refinements:** optimized polyphonic synthesis, contextual pages and inactive-control indicators, remembered Process settings, and confirmation before leaving takeover. The HTML manual, screen diagrams, device help, controller maps and Previous/Next navigation are updated.

Existing projects, sample files and MIDI parameter identities remain supported. Projects saved in 0.33.0 require 0.33.0 or newer to reopen; export a project backup before updating if you may need to return to an older version.

Install or update through Schwung Manager using `https://github.com/s3g/s3g-thru`, or download `s3g-thru-module.tar.gz` from this release. Requires Schwung 1.7.3 or newer. E16 Remote and E16 + Monolit examples are separate downloads.
